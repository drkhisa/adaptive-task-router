# Adaptive Task Router (ATR)

Скилл для ChatGPT и Codex, который помогает выбрать достаточную модель и глубину размышлений для текущей задачи.

Вы описываете нужный результат обычными словами. ATR оценивает задачу и контекст разговора: можно ли справиться в Chat, нужна ли многоэтапная работа в Work или изменение проекта в Codex. Затем выбирает подходящую доступную модель и минимально достаточный уровень размышлений.

Если настройки уже подходят, ATR молчит. Если мощности слишком много или мало, предлагает изменение и **ждёт вашего ответа перед выполнением задачи**. Если подходят несколько конфигураций, может показать до трёх вариантов, начиная с наиболее экономного. **Настройки он не переключает:** решение и переключение остаются за вами. После переключения сообщите об этом своими словами. Чтобы выполнить на текущих настройках, достаточно понятного согласия или команды продолжить: «продолжай», «продолжай так», «ок», «действуй», «делай». Точная фраза не требуется — ATR понимает намерение по контексту.

Основа репозитория — [skills/adaptive-task-router/SKILL.md](skills/adaptive-task-router/SKILL.md). В нём устойчивые правила выбора; сведения о моделях и интерфейсах лежат рядом в справочниках. Скилл упакован в OpenAI plugin для установки и распространения через GitHub.

## Кому это

**Сложный режим остаётся включённым для всего.** После трудной задачи вы просите исправить опечатку, а модель продолжает работать с высокими размышлениями. ATR предложит более простой вариант.

**Задача усложнилась, а настройки остались прежними.** Новые ограничения или неочевидная причина ошибки могут потребовать другой модели или большей глубины. ATR предложит повышение, если оно оправдано.

**Непонятно, где выполнять работу.** Объяснение функции обычно помещается в Chat. Правка репозитория с тестами относится к Codex. Исследование источников с готовым отчётом может выиграть от Work. ATR смотрит на характер работы, а не профессию или тему.

## Что будет на выходе

Рекомендация в порядке **среда → модель → размышления**, затем выбор: переключить настройки или продолжить на текущих. После предложения ATR останавливается и не выполняет задачу до вашего ответа:

> ⚙️ Рекомендую High → Light: это простое редактирование. Переключите настройки и сообщите, либо скажите продолжать на текущих.

> ⚙️ Рекомендую Astra → Luna: достаточно прямого преобразования текста. Переключите настройки и сообщите, либо скажите продолжать на текущих.

Названия используются только если соответствующие варианты доступны в вашей среде. При неизвестных настройках ATR не выдумывает их:

> ⚙️ Ориентир: Chat · быстрая доступная модель · минимальные размышления; текущие настройки не видны.

ATR рассматривает доступные подходящие модели, включая Luna, Terra, Sol и Astra. Альтернативы должны давать сопоставимое качество: точность, полноту и выполнение тех же условий задачи. Только после этого сравнивается экономичность. Sol · Medium может быть правильнее Terra · Medium для неоднозначной задачи; более слабый вариант не предлагается как равноценный без оснований. Учитываются результаты предыдущих попыток в видимом разговоре. При неизвестной доступности ATR рекомендует класс возможностей или условный вариант.

## Поведение в разговоре

- Известные настройки совпадают с достаточными — ATR молчит.
- Мощности слишком много или мало — предлагает нужные изменения и подходящие альтернативы, затем ждёт вашего решения перед выполнением.
- После переключения сообщите об этом любой понятной фразой. Любая ясная команда продолжить или обычное согласие разрешает выполнить задачу на текущих настройках без дополнительного подтверждения. «Ок» само по себе не означает, что настройки изменились; слова из примеров не являются обязательными командами.
- Вы продолжили работу без переключения или отказались — тот же совет больше не повторяет.
- На «продолжай» сохраняет рекомендацию для незавершённой работы.
- Новые вводные, ограничения и правки оценивает заново; оценка не обязательно меняет рекомендацию.
- Учитывает ваши явные предпочтения.
- После вашего решения продолжает основную задачу без повторного предложения. Если нужных инструментов нет, коротко объясняет необходимый переход.

Повторный непрошенный совет в той же задаче возможен только при существенных новых требованиях и спустя **не менее 30 минут** после предыдущего. Само время не является поводом напоминать. Быстрые дополнительные правки не запускают повторную рекомендацию. Если надёжных временных меток нет, ATR не угадывает интервал и сохраняет молчание; новую оценку можно запросить явно. Независимая новая задача оценивается отдельно.

## Установка

Нужен клиент ChatGPT/Codex с поддержкой plugin или локальных skills. Установка не зависит от компьютера автора. Доступ к моделям и инструментам определяется вашим аккаунтом, клиентом и правилами рабочего пространства.

Стабильная версия устанавливается из **`main`**, разработка идёт в **`dev`**. Публикация в каталоге OpenAI — отдельный процесс; для этой версии используется GitHub.

### Desktop, web и mobile

Локальная установка через Codex CLI или копирование папки skill **не является подтверждённой установкой на весь аккаунт**. Она проверена только в локальном Codex. Не рассчитывайте, что файлы с компьютера автоматически появятся в ChatGPT на телефоне или в браузере.

ChatGPT поддерживает доступные аккаунту plugins в Chat и Work на web, desktop и mobile. Чтобы plugin появился там, требуется поддерживаемая облачная установка и доступ к нему в выбранном аккаунте/workspace; одной записи в локальном marketplace недостаточно. ATR не содержит MCP server или hooks, поэтому его пакет не зависит от локального исполнения.

Для workspace документирован импорт из GitHub: администратор открывает **Admin → Plugins → Add → Import marketplace**, указывает URL репозитория, оставляет Path пустым для корня, выбирает ветку `main`, импортирует каталог и настраивает доступ. После импорта нужно проверить ATR в новых разговорах на каждом целевом клиенте. Это доступ в выбранном workspace, а не во всех личных и рабочих пространствах аккаунта.

Для произвольного личного аккаунта путь «установить наш GitHub plugin один раз и получить его во всех клиентах» пока не подтверждён документацией и не проверен. Публичный каталог — отдельный способ распространения, который в этой версии не используется. Проверка web/mobile остаётся открытой задачей.

Источники: [Plugins](https://learn.chatgpt.com/docs/plugins), [GitHub import and workspace access](https://learn.chatgpt.com/docs/enterprise/plugin-management).

### Через агент

Попросите своего агента:

```text
Установи plugin Adaptive Task Router из https://github.com/drkhisa/adaptive-task-router, ветка main.
```

Для установки только скилла:

```text
Установи skill из https://github.com/drkhisa/adaptive-task-router/tree/main/skills/adaptive-task-router
```

Способ зависит от инструментов агента. Если установка не поддерживается, используйте команды ниже. Скилл копируется папкой целиком, включая `references/` и `agents/`.

### Через Codex

Подключите каталог GitHub:

```sh
codex plugin marketplace add drkhisa/adaptive-task-router --ref main
```

Если ваш CLI поддерживает `codex plugin add`:

```sh
codex plugin add adaptive-task-router@adaptive-task-router
```

Первое имя — plugin, второе — каталог. В других поддерживаемых клиентах откройте Plugins Directory в desktop-приложении, выберите каталог **Adaptive Task Router** и установите plugin там. При необходимости перезапустите приложение; проверяйте скилл в новом разговоре.

### Из локальной копии

```sh
git clone --branch main https://github.com/drkhisa/adaptive-task-router.git
cd adaptive-task-router
codex plugin marketplace add .
```

Затем установите plugin тем же способом. Каталог указывает на `./` — корень репозитория, а не папку `.agents/plugins/`.

Для установки только скилла скопируйте `skills/adaptive-task-router` в пользовательскую папку skills; для Codex это обычно `~/.codex/skills/`. Не устанавливайте обе копии одновременно: они могут обнаруживаться как дубликаты.

### Проверка после установки

В новом разговоре явно выберите скилл и напишите:

```text
ATR подбери: исправь опечатки в коротком предложении и покажи рекомендацию.
```

Ожидается Chat, простая доступная модель и минимальные размышления. Задача с реальной правкой репозитория и тестами должна вести к Codex; одно объяснение вставленного кода — обычно к Chat.

При совпадении известных настроек обычный вызов может ничего не вывести от ATR. Для проверки попросите показать рекомендацию явно.

## Как использовать

Автоматическое включение разрешено: приложение может выбирать ATR по описанию задачи. **Это разрешение, а не гарантия вызова на каждом сообщении.**

Короткие команды:

- **«ATR»**
- **«ATR проверь»**
- **«ATR подбери»**

С командой можно дать новую задачу. Команда без задачи относится к текущей содержательной работе; если её ещё нет, ATR уточнит, что оценить. Упоминание названия в цитате не является командой.

Текстовые команды помогают выбору скилла, но не обходят его механизм. Для явного подключения в Codex нажмите `$` и выберите `adaptive-task-router`; в ChatGPT выберите установленный скилл через `@`. В клиентах с поддержкой текстового упоминания Codex можно использовать `$adaptive-task-router`.

Для видимой конфигурации даже при совпадении настроек: **«ATR проверь и покажи рекомендацию»**. Если рекомендации сейчас не нужны, сообщите об этом агенту.

## Как сокращается расход токенов

ATR делает короткую оценку внутри текущего ответа. Он не вызывает отдельную модель, не открывает браузер и не опрашивает инструменты только ради выбора режима. Очевидные задачи оценивает по кратким правилам; справочники читает при необходимости, использует уже видимые сведения.

Для неизменившегося продолжения повторная полная оценка не нужна. Проигнорированные рекомендации не повторяются даже при известном несовпадении настроек. Учитываются новые требования и видимый контекст; отдельные вызовы инструментов для отслеживания времени не делаются.

Загрузка скилла и справочников всё равно расходует контекст. Молчание не означает нулевого расхода. Точная экономия не измерена и не обещается; переключение влияет на последующую работу, а не меняет модель текущего ответа.

## Ограничения

Host может не сообщать текущую модель, уровень размышлений или доступные варианты. ATR оставляет эти данные неизвестными. Список моделей и сохранённые настройки по умолчанию не доказывают, какие настройки активны сейчас.

Справочники содержат датированный снимок документации; сведения среды имеют приоритет. Настройки API не обязательно доступны в интерфейсе ChatGPT. Переход в другую среду не переносит файлы и не выдаёт права.

ATR не переключает настройки, не создаёт новые задачи, не разрешает действия или субагентов и не гарантирует качество результата. Недостающие инструменты нельзя заменить большей глубиной размышлений.

## Обновление, удаление и распространение

Обновить подключённый каталог:

```sh
codex plugin marketplace upgrade adaptive-task-router
```

В локальной копии используйте `git pull --ff-only`. Plugin загружается из установленной кэшированной копии, поэтому после изменения исходников обновите или переустановите его и начните новый разговор.

Если CLI поддерживает эти команды, переустановка выглядит так:

```sh
codex plugin remove adaptive-task-router@adaptive-task-router
codex plugin add adaptive-task-router@adaptive-task-router
```

Иначе воспользуйтесь desktop-интерфейсом. Удалить подключённый каталог можно отдельно:

```sh
codex plugin marketplace remove adaptive-task-router
```

При установке только скилла удаляется скопированная папка `adaptive-task-router` из папки skills вашей среды.

Для распространения достаточно ссылки на GitHub и инструкции установки. Для воспроизводимого релиза стоит создать неизменяемый git tag и использовать его вместо `--ref main`. Сейчас предусмотрена установка из GitHub; публикация в каталоге OpenAI не выполнялась.
